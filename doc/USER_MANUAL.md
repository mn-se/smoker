# Smoker Pro ユーザーマニュアル

このマニュアルでは、M5Stack Core2 を使って Smoker Pro を操作し、温度制御や履歴データの管理を行う方法を説明します。

---

## 1. 初回セットアップ

デバイス起動時に Wi-Fi 設定がまだない場合は、自動的にセットアップモードに入ります。

1. スマートフォンの Wi-Fi 設定を開きます。
2. 「SMOKER-SETUP」というネットワークに接続します。
3. セットアップ画面が自動で表示されない場合は、ブラウザで http://192.168.4.1 を開きます。
4. 家庭用 Wi-Fi の情報と Meross スマートプラグの情報を入力し、「Save」を押します。
5. デバイスが再起動して、ネットワークに接続します。

---

## 2. スモーカーへのアクセス方法

ネットワーク接続後は、スマートフォンまたはブラウザからダッシュボードにアクセスできます。

### iPhone / Mac
ブラウザのアドレスバーに次を入力します。
👉 http://smoker.local

### Android / Windows
.local アドレスが使えない場合は、ルーター設定やネットワークスキャンツールでデバイスの IP アドレスを確認し、直接入力してください。

---

## 3. ホーム画面に追加する

毎回 URL を入力しなくて済むように、ダッシュボードをホーム画面に追加することをおすすめします。

1. ブラウザでダッシュボードを開きます。
2. iPhone では共有ボタンから「ホーム画面に追加」を選びます。
3. Android ではブラウザメニューから「ホーム画面に追加」を選びます。
4. アプリのアイコンが追加され、すぐに起動できるようになります。

---

## 4. 基本的な使い方

ダッシュボードから次の操作ができます。

- 自動温度制御を開始する
  - 目標温度を入力し「START AUTO CONTROL」を押すと、温度を安定させます。
- 手動オーバーライドを使う
  - FORCE ON でヒーターを継続的にオンにできます。
  - MONITOR では温度だけを記録し、ヒーターは動作しません。
  - STOP / IDLE でヒーターをオフにできます。
- PID 設定を調整する
  - P、I、D 値や PWM サイクルを変更し、設定を保存します。

---

## 5. 履歴データとメモの管理

システムは最近の温度履歴を保存し、セッションデータのエクスポートや復元ができます。

### データの保存（エクスポート）
スモーク後に記録を保存できます。
1. Session Info & Notes に日付・食材・場所・メモを入力します。
2. DOWNLOAD CSV をタップします。
3. 温度推移とセッション情報を含む CSV ファイルが保存されます。

### データの復元（インポート）
過去のセッションを確認したい場合は次の手順です。
1. IMPORT CSV をタップします。
2. 保存済みの CSV ファイルを選択します。
3. グラフとセッション情報が自動で復元されます。

### ログのリセット
新しいセッションを始める前に CLEAR LOG を押すと、保存済みデータをリセットできます。
